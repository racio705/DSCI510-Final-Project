# Original course submission

These sources preserve the repository's earlier analysis for comparison.
They depend on the original environment configuration and are not the supported
entry point. Use `python src/run_analysis.py` from the project root instead.

The original presentation in `doc/` is historical. Its reported R² of 0.45
does not match the user's saved `run_summary.csv`, which recorded in-sample
R² = 0.017678087357267946 on 21,328 cleaned records. The updated project
reports newly executed cross-validation results and explicit sample definitions.
Do not reuse the historical presentation's model metrics as validated results.
